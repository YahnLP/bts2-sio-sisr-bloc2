## Partie A – Calculer le TCO sur cinq ans (≈ 50 min)

**But :** construire le tableau de calcul dans ton tableur.

1. Crée un tableau avec, pour chaque solution, les **coûts ponctuels** et les **coûts annuels**.
2. Calcule d'abord la **consommation électrique** annuelle : ______ kWh, soit ______ € par an.
3. Complète :

| | A | B | C |
|---|---|---|---|
| Coûts ponctuels | | | |
| Coûts annuels | | | |
| **TCO sur 5 ans** | | | |

4. Ajoute une ligne **cumul par année** (année 1 à année 5). À quelle année la solution C devient-elle plus chère que la solution A, si c'est le cas ? ______

**J'anticipe.** Avant de calculer, laquelle des trois solutions penses-tu la moins chère, et pourquoi ? ______________________

<details markdown="1">
<summary>Éléments de réponse</summary>

Électricité : 0,25 kW × 8 760 h = **2 190 kWh**, soit **438 €** par an.

| | A | B | C |
|---|---|---|---|
| Coûts ponctuels | 3 000 + 1 000 + 480 + 800 = **5 280 €** | 3 000 + 1 500 = **4 500 €** | 1 500 + 800 = **2 300 €** |
| Coûts annuels | 500 + 250 + 2 880 + 438 = **4 068 €** | 500 + 250 + 4 320 + 438 = **5 508 €** | 1 728 + 720 + 600 = **3 048 €** |
| **TCO sur 5 ans** | **25 620 €** | **32 040 €** | **17 540 €** |

Cumul par année : A : 9 348 · 13 416 · 17 484 · 21 552 · 25 620 ; B : 10 008 · 15 516 · 21 024 · 26 532 · 32 040 ; C : 5 348 · 8 396 · 11 444 · 14 492 · 17 540. La solution C reste la moins chère sur toute la période avec ces hypothèses.

L'intuition « le matériel sur site est moins cher » est souvent **fausse** quand on compte le **temps d'administration**.

</details>

**Je comprends.** Pourquoi la solution B, sans licence, est-elle la plus chère ici ? ______________________

<details markdown="1">
<summary>Éléments de réponse</summary>

Parce que le **coût caché** (temps d'administration, formation) dépasse l'économie sur les licences. B évite 1 480 € de licences (une seule fois), mais coûte 2 heures d'administration de plus par mois que A, soit 1 440 € de plus **chaque année** (7 200 € sur cinq ans), plus 700 € de formation supplémentaire.

</details>

## Partie B – Analyse de sensibilité (≈ 30 min)

**But :** vérifier si la conclusion tient quand une hypothèse change.

Recalcule le TCO sur cinq ans dans chaque cas, en **changeant une seule hypothèse à la fois** :

| Hypothèse modifiée | TCO A | TCO B | TCO C | La moins chère |
|---|---|---|---|---|
| Aucune (référence) | | | | |
| Linux : administration à **4 h par mois** (comme Windows) | | | | |
| Abonnement hébergé **+ 25 %** | | | | |
| Une panne de **4 heures**, une fois, sur la solution A : coût d'indisponibilité (12 personnes × 40 € par heure) | | | | |

**Je comprends.** Quelle hypothèse a le plus d'effet sur la conclusion ? Pourquoi est-ce important de la valider avec le client ? ______________________

<details markdown="1">
<summary>Éléments de réponse</summary>

| Hypothèse modifiée | TCO A | TCO B | TCO C | La moins chère |
|---|---|---|---|---|
| Référence | 25 620 € | 32 040 € | 17 540 € | **C** |
| Linux à 4 h par mois | 25 620 € | **24 840 €** | 17 540 € | **C** (B passe sous A) |
| Abonnement + 25 % | 25 620 € | 32 040 € | **19 700 €** | **C** |
| Panne de 4 h sur A (12 × 40 € × 4 h = 1 920 €) | **27 540 €** | 32 040 € | 17 540 € | **C** |

L'hypothèse la plus sensible est le **temps d'administration** : elle fait passer B sous A. Elle dépend de la compétence du prestataire et de la complexité réelle : il faut la **valider** avec le client et le prestataire avant de conclure.

</details>

<details markdown="1">
<summary>Éléments de réponse</summary>

Éléments attendus (la **justification** compte plus que le signe) :

| Critère | A | B | C |
|---|---|---|---|
| Durée de vie | 0 : matériel standard, 5 ans | 0 : idem ; le système libre prolonge souvent la compatibilité du matériel | + : pas de matériel côté client |

Le **point d'attention** de la solution C est la localisation des données : elle appelle une **clause contractuelle** (voir S02).

## Partie D – Rédiger la recommandation (≈ 35 min)

Rédige, en **une demi-page**, ta recommandation au gérant du Cabinet Delorme. Elle contient :

1. La **solution recommandée** ;
2. Les **critères** retenus et la **comparaison chiffrée** (TCO sur cinq ans) ;
3. L'**analyse de sensibilité** : ce qui pourrait changer ta conclusion ;
4. Les **critères éthiques et environnementaux** ;
5. Les **conditions** de ta recommandation (clauses à négocier, questions restantes).

> [!WARNING]
> Une recommandation **sans les limites** n'est pas crédible. Écris ce qui te ferait changer d'avis.
