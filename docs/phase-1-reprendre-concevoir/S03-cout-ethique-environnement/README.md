# S03 – Coût de possession, éthique et environnement

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – bloc 2 |
| **Séance** | S03 (séance 3 sur 19) – Phase 1 |
| **Durée** | 4 heures |
| **Prérequis** | S02. |
| **Matériel** | Un tableur |
| **Compétences travaillées** | B2.1 (voir [le référentiel](../../ressources/referentiel.md)) |

> [!NOTE]
> **Question qui guide la séance :** *« Quelle solution coûte le moins sur cinq ans, et est-ce le seul critère ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Composer** le coût de possession d'une solution (achat, exploitation, maintenance, fin de vie) ;
2. **Comparer** deux solutions sur cinq ans avec un tableur ;
3. **Identifier** des contraintes éthiques et environnementales dans un choix d'infrastructure ;
4. **Argumenter** un choix en présentant ses critères et ses limites.
