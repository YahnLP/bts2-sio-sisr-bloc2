## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Mettre en œuvre** la deuxième réalisation ;
2. **Construire** la matrice de couverture des compétences ;
3. **Combler** les compétences insuffisamment couvertes ;
4. **Rédiger** la deuxième fiche descriptive.
