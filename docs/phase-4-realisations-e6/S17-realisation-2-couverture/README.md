# S17 – Réalisation 2 et matrice de couverture

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – bloc 2 |
| **Séance** | S17 (séance 17 sur 19) – Phase 4 |
| **Durée** | 4 heures |
| **Parcours** | **Cœur** – Deuxième réalisation E6 et couverture des compétences. Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Prérequis** | S16 |
| **Matériel** | Laboratoire ou environnement de l'entreprise |
| **Compétences travaillées** | B2.1 · B2.2 · B2.3 (voir [le référentiel](../../ressources/referentiel.md)) |

> [!NOTE]
> **Question qui guide la séance :** *« Tes deux réalisations couvrent-elles tout le bloc 2 ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Mettre en œuvre** la deuxième réalisation ;
2. **Construire** la matrice de couverture des compétences ;
3. **Combler** les compétences insuffisamment couvertes ;
4. **Rédiger** la deuxième fiche descriptive.
