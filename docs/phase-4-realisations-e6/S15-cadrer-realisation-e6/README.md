| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – bloc 2 |
| **Séance** | S15 (séance 15 sur 19) – Phase 4 |
| **Durée** | 4 heures |
| **Prérequis** | S01 à S14. |
| **Matériel** | Fiches descriptives vierges |
| **Compétences travaillées** | B2.1 · B2.2 · B2.3 (voir [le référentiel](../../ressources/referentiel.md)) |

> [!NOTE]
> **Question qui guide la séance :** *« Quelle réalisation montrer, et comment prouver qu'elle respecte l'annexe II.E ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Lire** les attendus de l'épreuve et la grille d'évaluation ;
2. **Choisir** deux réalisations qui couvrent ensemble tout le bloc 2 ;
3. **Vérifier** la conformité de l'environnement à l'annexe II.E ;
4. **Planifier** la réalisation.
